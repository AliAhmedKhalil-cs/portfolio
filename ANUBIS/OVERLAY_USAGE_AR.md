## 🎯 الجمع بين التأثيرات

يمكنك دمج عدة فئات للحصول على تأثير أفضل:

### مثال 1: تأثير ملكي كامل
```html
<img src="anubis.jpg" 
     class="image-frame-cartouche image-corner-lotus image-lighting-torch image-overlay-papyrus" />
```

### مثال 2: عرض متحفي
```html
<img src="artifact.jpg" 
     class="image-style-glass image-vignette-tomb image-texture-linen" />
```

### مثال 3: تأثير أنوبيس المقدس
```html
<img src="deity.jpg" 
     class="image-aura-anubis image-accent-scarab image-animation-dust" />
```

### مثال 4: عرض الكنز
```html
<img src="treasure.jpg" 
     class="image-frame-hieroglyphic image-overlay-sand image-animation-dust" />
```

## 📱 الخصائص الرئيسية

✓ **CSS فقط** - لا تحتاج JavaScript
✓ **سريع جداً** - تسريع بواسطة GPU
✓ **استجابة** - يعمل على جميع أحجام الشاشات
✓ **آمن للصور** - لا يؤثر على الصور الأصلية
✓ **قابل للتخصيص** - عبر متغيرات CSS

## 💡 نصائح الاستخدام

1. **استخدم صور عالية الجودة** - التأثيرات تحسن، لا تخلق!
2. **اختبر على أجهزة مختلفة** - تأكد من المظهر على الهاتف والكمبيوتر
3. **لا تبالغ** - استخدم 1-3 تأثيرات فقط لكل صورة
4. **اجمع بحكمة** - بعض التأثيرات تعمل أفضل معاً
