## 🎯 How to Customize

### Add a New Place
Edit `data/places.json`:
```json
{
  "id": 16,
  "name": "Your Site",
  "arabicName": "الموقع",
  "region": "Luxor",
  "category": "Temples",
  "image": "assets/your-image.svg",
  "excerpt": "Short description",
  "fullStory": "Long story...",
  // ... more fields
}
```

### Add a Ruler
Edit `data/rulers.json`:
```json
{
  "name": "Pharaoh Name",
  "arabicName": "الاسم بالعربية",
  "era": "Dynasty (dates)",
  "achievements": [...],
  "monuments": [...]
}
```

### Change Colors
Edit `css/styles.css` (line 6):
```css
--color-primary: #D4AF37;    /* Change gold */
--color-dark: #0A0A0A;       /* Change black */
```

### Replace Images
Add your own images to `/assets`:
```json
"image": "assets/your-image.jpg"
```

## 🆘 Quick Troubleshooting

**Images not loading?**
- Check file paths in JSON (use relative paths)
- Ensure images are in `/assets` folder

**Styles look wrong?**
- Clear browser cache (Ctrl+Shift+Delete)
- Hard refresh (Ctrl+F5)

**3D museum blank?**
- Check browser console (F12)
- Ensure Three.js CDN loads
- Try different browser

**Language not switching?**
- Check language buttons (top-right)
- Refresh page

**JSON errors?**
- Validate JSON at jsonlint.com
- Check for trailing commas
- Ensure quotes are correct
