## 🎯 THE TRANSFORMATION

### Problem
Card icons were **too small, visually weak, and felt like UI icons instead of museum artifacts**.

### Solution
Transformed `.card__icon` into a **dominant, ceremonial, pharaonic visual element** representing power, ritual, and eternity.

### Result
Cards now feel like **sacred artifacts placed inside museum display cases**—heavy, silent, eternal.

## 🎨 DESIGN SPECIFICATIONS

### Size (Responsive)
```
Desktop: 96px × 96px
Tablet:  80px × 80px
Mobile:  72px × 72px
```

### Container
```
Shape:      Cartouche/stone tablet (12px radius)
Background: Subtle gold gradient (8-15% opacity)
Border:     2px gold frame (25% opacity)
Shadow:     Carved relief effect (inset)
Padding:    32px (desktop), 24px (mobile)
```

### Icon
```
Color:      Antique Gold (#d4af37)
Style:      Mask-image rendered (PNG technique)
Size:       Fills 100% of container
Rendering:  CSS mask-image with currentColor
```

### Interaction
```
Hover:      Brightness increase (1.08)
Shadow:     Enhanced depth on hover
Animation:  None (respects prefers-reduced-motion)
Duration:   Smooth transition (0.3-0.5s)
```
