🔒 سياسة الخصوصية

نحن ملتزمون بحماية خصوصيتك وبياناتك الشخصية

آخر تحديث: يناير 2025

1. مقدمة

نحن في موقع وكيل 1xbet في مصر نقدر خصوصيتك ونلتزم بحماية معلوماتك الشخصية. توضح هذه السياسة كيفية جمع واستخدام وحماية المعلومات التي تقدمها لنا.

2. المعلومات التي نجمعها

المعلومات الشخصية:

  • • الاسم الكامل
  • • عنوان البريد الإلكتروني
  • • رقم الهاتف
  • • تاريخ الميلاد
  • • معلومات الدفع (مشفرة)

المعلومات التقنية:

  • • عنوان IP
  • • نوع المتصفح
  • • نظام التشغيل
  • • ملفات تعريف الارتباط (Cookies)

3. كيفية استخدام المعلومات

نستخدم المعلومات المجمعة للأغراض التالية:

  • • تقديم خدماتنا وتحسينها
  • • التواصل معك بشأن حسابك والخدمات
  • • إرسال العروض والتحديثات (بموافقتك)
  • • ضمان الأمان ومنع الاحتيال
  • • الامتثال للمتطلبات القانونية

4. مشاركة المعلومات

نحن لا نبيع أو نؤجر معلوماتك الشخصية لأطراف ثالثة. قد نشارك المعلومات في الحالات التالية:

  • • مع مقدمي الخدمات الموثوقين لتشغيل موقعنا
  • • عند الحاجة للامتثال للقوانين
  • • لحماية حقوقنا وسلامة المستخدمين
  • • بموافقتك الصريحة

5. أمان المعلومات

نتخذ تدابير أمنية صارمة لحماية معلوماتك:

  • • تشفير SSL لجميع البيانات المنقولة
  • • خوادم آمنة ومحمية
  • • وصول محدود للموظفين المخولين فقط
  • • مراقبة مستمرة للأنشطة المشبوهة
  • • نسخ احتياطية منتظمة
