# Portfolio Website - Ibrahem Kassap

## 🚀 Professional Portfolio & Blog

A modern, SEO-optimized portfolio website showcasing web development services, projects, and technical blog articles.

## ✨ Features

- **Responsive Design**: Mobile-first approach with glassmorphism effects
- **SEO Optimized**: Structured data, meta tags, sitemap, and robots.txt
- **Interactive Chatbot**: AI-powered assistant for visitor engagement
- **Blog Section**: Technical articles on HTML, CSS, JavaScript, and SEO
- **Contact Forms**: EmailJS integration for audit requests and inquiries
- **Portfolio Showcase**: 50+ projects with live demos
- **Performance Optimized**: Fast loading with Core Web Vitals optimization

## 🚀 Getting Started

1. Clone the repository
2. Open `index.html` in your browser
3. Configure EmailJS credentials in `main.js`
4. Update personal information in all HTML files
5. Deploy to your hosting service

## 📧 Contact Integration

The website uses EmailJS for form submissions. To set up:

1. Create an account at [EmailJS](https://www.emailjs.com/)
2. Get your Public Key, Service ID, and Template ID
3. Update credentials in `main.js`:
   ```javascript
   emailjs.init("YOUR_PUBLIC_KEY");
   emailjs.sendForm('YOUR_SERVICE_ID', 'YOUR_TEMPLATE_ID', form);
   ```
